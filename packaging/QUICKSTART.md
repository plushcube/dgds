# Быстрый старт

Пакет несёт два приложения: `dgds-server` и `dgds-client`. Ниже — стенд из двух
процессов, который проходит сценарий целиком: регистрация, публикация, каталог,
покупка и выдача с расшифровкой. Прав администратора и установки не требуется.

Если пакет распакован из архива, а не установлен, замените `dgds-server` и
`dgds-client` на `bin/dgds-server` и `bin/dgds-client` из каталога распаковки.

## Запуск сервера

```sh
dgds-server --root /tmp/dgds-stand --port 0
```

Сервер создаст каталог данных, выпустит самоподписанный сертификат и напечатает
адрес в строке «Слушаю». Порт из этой строки понадобится клиенту.

```
Каталог данных:  /tmp/dgds-stand
Сертификат:      /tmp/dgds-stand/tls/server.crt
Отпечаток:       ...
Закрепление:     ...
Слушаю https://127.0.0.1:54321
```

## Запуск клиента

Во втором терминале подставьте порт из строки «Слушаю»:

```sh
dgds-client --certificate /tmp/dgds-stand/tls/server.crt --port 54321 --device /tmp/dgds-stand/device
```

Клиент зарегистрирует автора и покупателя, опубликует образец текста, напечатает
каталог, купит публикацию и выведет расшифрованное содержимое между строками
`=== потребитель выводит полученный контент ===` и `=== конец контента ===`.

Свой файл для публикации задаётся ключом `--text <файл>`.

## Что проверить

- каноническая форма выведенного текста совпадает с исходной, а в самом тексте
  видны вставленные метки — невидимые символы, кодирующие покупку;
- открытого текста не остаётся ни в каталоге сервера, ни в каталоге устройства:
  в `/tmp/dgds-stand` лежат только шифротекст, ключи и метаданные;
- повторная публикация того же содержимого отвергается как дубликат.

## Запуск в контейнере

Образ публикуется вместе с релизом. Сервер поднимается одной командой, сертификат
вынимается из тома, клиент работает из того же пакета:

```sh
docker run --name dgds --detach --publish 127.0.0.1:8443:8443 --volume dgds-data:/data \
  ghcr.io/plushcube/dgds:latest

# сертификат выпускается при первом запуске, дождитесь его появления
until docker exec dgds test -f /data/tls/server.crt; do sleep 1; done
docker cp dgds:/data/tls/server.crt ./server.crt

dgds-client --certificate ./server.crt --port 8443 --device /tmp/dgds-device
```

Подробности разворачивания — в `docs/deployment.md` внутри пакета.
